# CVB-010 — Initialize the Monorepo

## Type

Technical Task

## Priority

P0

## Story Points

3

## Goal

Create the initial TypeScript monorepo structure for the CV Builder project.

The repository must support:

* Next.js frontend
* NestJS backend API
* BullMQ worker
* Shared internal packages
* Root-level development commands
* Future Docker integration

## Scope

Create and configure:

* npm workspaces
* Turborepo
* Root `package.json`
* Root TypeScript configuration
* Shared ESLint configuration
* Prettier configuration
* Application directories
* Shared-package directories
* Root scripts
* Git ignore rules

## Technical Requirements

* Use npm workspaces.
* Use Turborepo for task orchestration.
* Use strict TypeScript settings.
* Use a shared base TypeScript configuration.
* Add root commands for:

  * development
  * build
  * lint
  * type checking
  * testing
  * formatting
* Configure Prettier.
* Prepare a shared ESLint package.
* Do not initialize Next.js, NestJS, or worker application code in this ticket.
* Do not add Dockerfiles or Docker Compose files in this ticket.
* Do not add database configuration in this ticket.

## Root Scripts

The root `package.json` should expose scripts similar to:

```json
{
  "scripts": {
    "dev": "turbo run dev",
    "build": "turbo run build",
    "lint": "turbo run lint",
    "typecheck": "turbo run typecheck",
    "test": "turbo run test",
    "format": "prettier --write .",
    "format:check": "prettier --check ."
  }
}
```

Codex may adjust script names when required by the selected Turborepo version, but the same capabilities must remain available.
